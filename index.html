My NextGen.AI

Building an AI companion that lives on local hardware — with a face, voice, vision, and memory.

🤖

Local-First AI

Runs entirely on local hardware via LM Studio. No cloud APIs, no data leaves your machine. Uses frontier open-weight models (Llama, Nemotron, Qwen) served locally at 1234/v1.

👁️

Computer Vision

MediaPipe face landmarking at 10Hz from webcam. Tracks gaze, expression, and presence — so the companion reacts to you in real time, not just text.

🗣️

Neural Voice

Edge TTS (en-US-GuyNeural) + ElevenLabs streaming. Lip-synced via FasterLivePortrait (ONNX + DirectML) — her face moves with every syllable.

🧠

Persistent Memory

SQLite-backed long-term store with importance scoring, deduplication, and contextual recall. Remembers conversations across sessions.

🧩

3D Embodiment

Panda3D-rendered hologram body in a procedural Blade Runner 2049 apartment. Real-time pose, breathing, and idle animations at 24fps.

🔒

Privacy by Design

Zero telemetry. All inference, vision, voice, and memory stay local. Works fully offline once models are downloaded.

Tech Stack

Core Runtime

  • Python 3.14 — main loop, orchestration
  • Panda3D — 3D scene graph, rendering
  • OpenCV + MediaPipe — vision pipeline
  • NumPy — numerical compute

AI / ML

  • LM Studio (localhost:1234) — OpenAI-compatible LLM server
  • FasterLivePortrait (ONNX) — talking-head video synthesis
  • Edge TTS / ElevenLabs — neural text-to-speech
  • InsightFace / MediaPipe — face analysis

Storage & Memory

  • SQLite (joi_memory.db) — long-term memory
  • JSON (ava_memory.json) — seed/export data
  • Local file cache — posters, models, assets

Personas & Modes

  • Companion / Friend / Family / Adult / Doctor
  • Configurable system prompts per persona
  • Real-time persona switching
